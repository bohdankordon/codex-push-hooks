Mechanics

Short-delay plus fallback: two-tier scheduling

Every push checks whether you have already responded. If you are back, it stops; if not, it escalates.

0s

Event triggers

Claude Code / Codex / Reasonix / dsh need an approval, are waiting for input, or finish a task. Question tools (Codex request_user_input, Reasonix ask, dsh ask_user_question) are detected precisely through PreToolUse, and the PostToolUse that follows an answer cancels the delayed notifications for that call.

3 ~ 15s

Short-delay notification — instant reach

macOS banners, Telegram messages, Bark / Pushover / ntfy phone pushes. Only the agent, status, project, and a one-line summary — no permission details.

✓ Saw the notification and came back? The remaining pushes are cancelled automatically.

Fallback notification — async safety net

WeCom / Feishu / DingTalk / Slack / Discord group messages. Feishu uses a message card and the other channels use approximate Markdown / embed templates; the first line is always the short summary.

✓ Did the short-delay notification already solve it? The fallback is never sent. Zero noise.

Install

Two commands and you are live

Claude Code, Codex CLI, Reasonix, and dsh are all supported: install the plugin in one step or deploy the standalone scripts.

Inside Claude Code, run:

/plugin marketplace add MarioZZJ/cc-notify-hooks
/plugin install cc-notify-hooks@cc-notify-hooks

After installing, run /cc-notify-hooks:config to start the interactive configuration wizard.

Add the marketplace and install the plugin:

codex plugin marketplace add MarioZZJ/cc-notify-hooks --ref v2.4.0
codex plugin add cc-notify-hooks@cc-notify-hooks

Enable hooks in ~/.codex/config.toml (required):

[features]
codex_hooks = true

The marketplace lives at the repository root; the actual plugin directory is plugins/cc-notify-hooks/.

Codex hooks use PLUGIN_ROOT to locate the scripts and PLUGIN_DATA to store configuration and session state, so they do not depend on a fixed cache path. After installing or upgrading, review and trust the changed hooks under /hooks.

Reasonix reads reasonix-plugin.json from the repository natively (5 hooks, Claude-shaped payloads):

reasonix plugin install git:github.com/MarioZZJ/cc-notify-hooks --yes

For local development, link the install so repository changes take effect immediately:

git clone https://github.com/MarioZZJ/cc-notify-hooks.git
reasonix plugin install ./cc-notify-hooks/plugins/cc-notify-hooks --link --yes

Configuration is written to ~/.reasonix/cc-notify-hooks/notify.json; restart the Reasonix session after installing (/new does not reload hooks).

dsh has no external shell hooks; the repository ships a zero-dependency host plugin that subscribes directly to dsh interception points (approvals, turn ends, questions, and more):

git clone https://github.com/MarioZZJ/cc-notify-hooks.git
cd cc-notify-hooks && bash install/dsh.sh

The installer symlinks the plugin into ~/node_modules/@dsh-local/dsh-cc-notify and appends an insert entry to ~/.dsh/cordis.patch.yml — dsh hot-loads it, so running sessions pick it up immediately.

git clone https://github.com/MarioZZJ/cc-notify-hooks.git
cd cc-notify-hooks
bash install.sh                  # interactively choose a target
bash install.sh claude           # install into Claude Code directly
bash install.sh codex            # install into Codex CLI directly
bash install.sh reasonix         # install into Reasonix directly
bash install.sh dsh              # install into dsh (DeepSeek Harness) directly

The installer walks you through channel selection and credential entry, then writes the configuration for the tool you chose.

Features

Built for agent workflows

⚡ Smart cancellation

Come back and interact, and every queued push is voided. You are never interrupted twice.

🔇 Subagent filtering

Subtasks never trigger a push; only the main agent's key events reach you.

🕑 Rate limiting

Throttled per session and event category; structured questions deduplicate by tool_use_id so the next real question is never swallowed.

🔧 Adjustable delays

Every channel has its own delay. Telegram at 5 seconds, Bark at 30, Feishu at 10 minutes — your call.

🌏 Zero-config macOS

macOS users are ready right after installing, with native system notifications and no service to sign up for.

🔌 Four integrations

One configuration covers Claude Code, Codex CLI, Reasonix, and dsh: two marketplaces, a native Reasonix manifest, and a dsh host plugin, all configured at once.

💬 Structured question notifications

Codex request_user_input, Reasonix ask, and dsh ask_user_question enter the existing notification queue immediately; answering cancels only the reminders for the current session that have not been sent yet.
